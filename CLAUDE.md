# MCA: Quests — NeoForge 1.21.1 Port

## Orientation

This is the NeoForge 1.21.1 port of MCA: Quests at feature version 1.5.3. The mod version stays `1.5.3` (see "Version policy" below); the platform is expressed by the Minecraft version and loader targeting, not by the mod's own semver.

Package layout and registration inventory live in `MODMAP.md` (generated by `.mcmod-tools/modmap.py`). Player-facing docs are `README.md`, `CONFIG.md`, `DATAPACK.md`, `TOWNSTEAD.md`, `FTBQUESTS.md`; `docs/` holds the implementation spec and other technical details.

## Quick Reference

- **Mod ID**: `mcaquests` — **Package**: `dev.otectus.mcaquests`
- **MC / NeoForge / mod version**: `gradle.properties`. Mappings `official`, Java 21 toolchain (build.gradle:16)
- **Network protocol version**: `QuestNetwork.PROTOCOL_VERSION` (network/QuestNetwork.java:41) — protocol 15; bump it whenever a packet's shape changes; client and server must match exactly.

Version numbers live only in `gradle.properties`; `processResources` expands them into `neoforge.mods.toml` and `pack.mcmeta`. Never hard-code one elsewhere, including documentation.

## Key Dependencies

- **MCA Reborn** — mandatory at runtime, never a compile dependency; reached only through reflective binding in `compat/mca` (package root probe at startup)
- **FTB Quests stack** — `compileOnly`, never shipped; reached through bridge in `compat/ftbq`; set `enableFtbqInDev=true` to get it in dev runs
- **MCA: Reputation** — optional; reached through bridge in `compat/reputation`; compile surface is the sibling's class output
- **Townstead** — optional; reached through purely reflective binding in `compat/townstead` (no compile link, no shipped code)
- **JourneyMap API** — `compileOnly`, never shipped; used only in `compat/journeymap/` (loaded via JourneyMap's plugin discovery, not by reflection)
- **Xaero's Minimap** — optional; reached through purely reflective binding in `compat/xaero` (no compile link, no shipped code)

## Conventions

- This mod registers no blocks, items or entities, so there is no `DeferredRegister` anywhere. Almost all "registration" here is optional-mod binding, not NeoForge registries.
- `@EventBusSubscriber` with no `bus=` (FORGE) is the default; MOD bus appears only where mod setup needs it (client/QuestClientSetup.java:24). Events are `net.neoforged.neoforge.event.**` not `net.minecraftforge.event.**`.
- No access transformer. Cross-mod access goes through reflection/MethodHandles instead.
- Config is `ModConfigSpec` in `McaQuestsConfig.java`, split into `COMMON_SPEC` (server-safe) and `CLIENT_SPEC`. Every key is documented in `CONFIG.md`.
- Optional mods (MCA, Townstead, FTB Quests, MCA: Reputation, Xaero) are gated on `ModList.get().isLoaded(...)` and reached only through a binding in `compat/<mod>/` that resolves types by name at runtime. Nothing in `src/main/java` may statically import a third-party mod type; `NoMcaStaticLinkTest` enforces that, and each integration has a Noop bridge for the absent case. **Exception:** `compat/journeymap/` is typed against JourneyMap's compile-only API 2.0 and loaded only via JourneyMap's plugin discovery; `NoMinimapStaticLinkTest` allows `journeymap/` references only under `dev/otectus/mcaquests/compat/journeymap/`. The map layer uses an empty registry instead of a Noop bridge.
- Mixins: `mcaquests.mixins.json`, a client-only set of two classes (`MinecraftGlowMixin`, `ScreenAccessor`). Plain SpongePowered Mixin, `compatibilityLevel: JAVA_21`, no refmap, no MixinExtras.
- Common code must not import `net.minecraft.client`; the two `mixin/` classes are the deliberate exception.
- Commands: `/mcaquests` runs on the server command dispatcher (common), while `/mcaquestsclient` runs on the client dispatcher from `client/ClientCommands.java` when the player is in-game.

## Networking

All packets implement `CustomPacketPayload` with `StreamCodec` (NeoForge 21.1 idiom). The network channel is versioned at protocol 15 — clients and servers of different protocol versions cannot join.

- Wire data: Components use `ComponentSerialization.TRUSTED_STREAM_CODEC`; ItemStacks use `ItemStack.OPTIONAL_STREAM_CODEC`.
- Registration: 21 payloads via `PayloadRegistrar.versioned("15")` (network/QuestNetwork.java:55).
- C2S payloads (client → server): checked with `if (!(ctx.player() instanceof ServerPlayer sp)) return;`, then existing body, no `enqueueWork`.
- S2C payloads (server → client): routed through `ClientPayloadHandlers` static methods to avoid DistExecutor overhead.

## Player Data & World Saves

**Forge capability → NeoForge data attachment (one-way migration on first login).**

- Player quests: Stored in NeoForge data attachment `mcaquests:player_quests` (was Forge capability `mcaquests:player_quests`).
- Automatic migration: On first login in a 1.20.1 world, player NBT is read from `playerdata/<uuid>.dat` → `ForgeCaps` → `mcaquests:player_quests` attachment, marked `migrated_from_forge`. Migration is one-way; worlds must be backed up before upgrading.
- Failed reads: Retried on next login, never block login.
- World saves (unchanged names):
  - `mcaquests_projects` (village project progress)
  - `mcaquests_situations` (active situations)
  - `mcaquests_townstead_signals` (Townstead integration state)
  - `mcaquests_dead_givers` (recorded giver deaths, pruned after 20 in-game days)
  - `mcaquests_pending_hearts` (deferred heart rewards)

## Configuration

Config is now NeoForge `ModConfigSpec`. File names (`mcaquests-common.toml`, `mcaquests-client.toml`), all keys, defaults, and ranges are unchanged from Minecraft 1.20.1 — 1.20.1 config files load as-is.

## Rendering

- **Screens** (ProjectMenuScreen, QuestLogScreen, QuestMenuScreen, JournalScreen): single `super.render` call first (after widget updates), foreground overlays after, tooltips last. See commit `863b357` for the diff pattern.
- **Toasts** (`client/McaToast.java`): background draw is `blitSprite(withDefaultNamespace("toast/advancement"), ...)`.
- **HUD tracker** (`client/QuestHudOverlay.java`): implements `LayeredDraw.Layer`, registered via `RegisterGuiLayersEvent.registerAboveAll(...)`.
- **Quest marker** (`client/marker/QuestMarkerRenderer.java`): uses 1.21 vertex API with `ByteBufferBuilder` + `MultiBufferSource.immediate(...)`. Partial tick is obtained from `DeltaTracker.getGameTimeDeltaPartialTick(boolean)`.

## Reflection Boundaries

To keep MCA/Townstead/Xaero binding localized and safe:

- **No static MCA imports** anywhere (enforced by `NoMcaStaticLinkTest`). MCA classes are resolved by name at runtime in `compat/mca/McaBinding.java`.
- **No static Townstead imports** anywhere (enforced by `NoTownsteadStaticLinkTest`). Types are resolved by name and invoked via `MethodHandle`.
- **No static Xaero imports** anywhere (enforced by `noCompiledClassReferencesXaero` in `NoMinimapStaticLinkTest`, ~line 86). Types are resolved by name.
- **JourneyMap only in `compat/journeymap/`** (enforced by `NoMinimapStaticLinkTest`). It is compiled against the plugin API 2.0 and discovered via `@JourneyMapPlugin(apiVersion = "2.0.0")` by JourneyMap's own plugin loader, not reflectively.

## Version Policy

The mod version stays `1.5.3` even on this NeoForge port. A platform port (Minecraft version change, loader change) does not bump the mod's semver; the platform is expressed by artifact metadata and the artifact's own MC/loader targeting. This is consistent with Minecraft release practices (Bedrock stays X.Y.Z across launchers) and avoids creating false semver breaks when no API or behavior changed.
